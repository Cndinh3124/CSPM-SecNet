# SecNet CSPM Automation v1
Terraform -> AWS CSPM Lab -> Prowler -> Normalization/Risk -> Gemini -> CSV/XLSX/HTML/JSON.
Prowler remains the assessment/dashboard layer. SecNet CSPM adds orchestration, AI enrichment and evidence/reporting.
Safety: lab resources are tagged Project=CSPM and CSPMTest=true; intentional vulnerabilities are disabled by default; Gemini is advisory only; scan performs no remediation.
